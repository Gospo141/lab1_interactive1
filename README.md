# Лабораторна робота №1

Лічильник розроблено на Flutter. Ціле число додається до поточного значення,
команда `Avada Kedavra` скидає його до нуля. При помилковому вводі застосунок
показує повідомлення й зберігає поточне значення.

```sh
flutter pub get
flutter run
```
