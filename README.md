# Розумний дім

Лабораторні роботи з дисципліни «Розроблення мобільних додатків».
Студент: Рудик Андрій, КБ-410.

## Лабораторна робота №2

Додано екрани входу, реєстрації, профілю й головного екрана з тестовими IoT-пристроями. Навігація використовує іменовані маршрути. AuthLayout, CustomButton, CustomTextField, DeviceCard і SensorCard винесено в окремі віджети. Сітка адаптується до ширини екрана.

[Методичні вказівки](https://github.com/Berezhnyj/mobile-app-development-labs/tree/lab-02).
